# css-responsive

A skill-first Claude Code plugin for opinionated, mobile-first responsive CSS.

Auto-invokes when you work on CSS/SCSS styling and layout — responsive design, flexbox vs grid, media/container queries, dark mode, design tokens, and relative units.

## What it encourages

- Mobile-first, breakpoint-light layouts
- Relative units (`rem`/`%`/`fr`/`ch`/`clamp`) over pixels
- Design tokens via CSS custom properties, with theme-swappable dark mode
- Deliberate flexbox (1D) vs grid (2D) choices, container queries for components
- No magic numbers, no reflexive `!important`
